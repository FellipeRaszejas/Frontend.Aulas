# 💰 FinSight - Plataforma de Controle Financeiro Inteligente

> Uma solução completa, moderna e responsiva para gestão patrimonial, investimentos e controle de orçamentos, desenvolvida com as melhores práticas de design web moderno.

---

## 🚀 Sobre o Projeto

O **FinSight** foi idealizado para centralizar a vida financeira de usuários que buscam autonomia e inteligência nos investimentos. A plataforma simula a experiência de um aplicativo fintech de alta performance, permitindo acompanhar o patrimônio consolidado, gerenciar contas em múltiplos bancos, estabelecer metas visuais de longo prazo e explorar oportunidades de investimento alinhadas ao perfil do usuário (como o perfil de *Investidor Passivo*).

---

## ✨ Principais Funcionalidades

*   **📊 Dashboard Principal:** Visão consolidada do mês, evolução patrimonial através de gráficos interativos, acesso a orçamentos ativos e inteligência financeira integrada (FinSight IA Assistant).
*   **🔗 Sincronização Open Finance:** Página de transações com um **Modal Dinâmico** que incentiva a conexão de todos os bancos para acesso ao histórico real completo.
*   **📈 Central de Investimentos:** Portfólio diversificado divido em categorias estratégicas como Renda Fixa (Caixinhas e Tesouro Direto), Renda Variável (Ações e FIIs), Fundos e Criptoativos.
*   **🎯 Metas & Poupança:** Cartões visuais enriquecidos com imagens reais de alta qualidade para acompanhamento de objetivos (Viagem, Casa Própria, Carro Novo) com barras de progresso dinâmicas.
*   **👤 Perfil do Usuário Integrado:** Navbar responsiva com identificação de avatar, nome e tag personalizada indicando a classe do investidor.

---

## 🛠️ Tecnologias Utilizadas

*   **HTML5 Semântico:** Estruturação limpa e otimizada de páginas.
*   **Tailwind CSS (via CDN):** Estilização ágil baseada em classes utilitárias, garantindo design system unificado, paleta de cores customizada e responsividade fluida.
*   **JavaScript (Vanilla):** Lógica simples e eficiente para controle de modais e interatividade de componentes.
